# 论文规划：从午间新能源富余充电到晚峰上调备用

## 1. 暂定题目

中文：

> 从午间新能源富余充电到晚峰上调备用：DK1 顺序市场中的储能联合决策

英文：

> From Renewable-Rich Midday Charging to Evening Upward Reserve: Sequential Battery Co-optimization in DK1

题目中的“新能源富余充电”指模型充电与高风光占比、低价或负价格时段对齐，不表示已经观测到真实弃电削减。

## 2. 论文要回答的问题

> 在 aFRR 容量承诺早于日前能量交易的 DK1 市场中，储能能否利用午间新能源富余时段充电，并在晚峰保留可交付的上调能力；不确定性处理能否改善午间吸收、晚峰交付、收益与风险之间的权衡？

论文围绕三个相连问题组织：

| 问题 | 论文中的作用 |
|---|---|
| DK1 是否存在午间新能源富余与晚峰上调价值的时段错配 | 经验事实与研究动机 |
| 联合决策是否形成午间充电—晚峰 SOC 与备用转移 | 核心应用结果 |
| 概率信息和实际交付反馈如何改变收益—交付权衡 | 方法与风险结果 |

基于当前文献库，尚未发现完整结合以下内容的工作：

1. 后改制 DK1 的 07:30 备用容量—12:00 日前能量顺序；
2. 午间新能源富余时段充电到晚峰上调能力的路径量化；
3. 使用实际激活结算储能交付与未交付；
4. 在交付结果延迟可见时，研究固定风险与自适应风险处理的差异。

该判断限定于当前检索范围。论文使用“现有近邻工作尚未共同覆盖”，不使用无法穷尽证明的“首次”。

## 5. 当前可写入的结果

### 5.1 市场时段事实

| 指标 | 午间 10:00--15:59 | 晚峰 17:00--21:59 |
|---|---:|---:|
| 日前均价 | 64.52 EUR/MWh | 129.10 EUR/MWh |
| 日前负价占比 | 7.72% | 0.52% |
| 上调容量均价 | 9.84 EUR/MW | 36.86 EUR/MW |
| 风光/负荷 | 0.800 | 0.713 |

晚峰日前均价在 89.9% 的日期高于午间；晚峰上调容量均价在 93.7% 的日期高于午间。这些是 RQ1 的支持证据。

### 5.2 预测与决策事实

| 主结果 | 数值 |
|---|---|
| B0 仅日前总收益 | 174,085 EUR |
| B1 简单顺序总收益 | 433,618 EUR |
| B2_FB0 点预测联合总收益 / 未交付 | 567,075 EUR / 12.86% |
| B3_hist_paired 总收益 / 未交付 | 635,939 EUR / 8.86% |
| B3 相对 B2 日收益差 | +326.37 EUR，95% 区间 195.31--475.18 |
| B3 相对 B2 日级未交付占比差 | -1.462 个百分点，95% 区间 -2.627 至 -0.450 |
| 复杂高斯场景 | 收益 661,826 EUR，未交付 10.48%；不是全面最优 |
| 固定风险诊断 | 名义 5% VaR 实际超越最高 44.4% |

这些结果支持概率场景的决策价值与直接评价实际交付的必要性，尚不支持“增加午间充电”或“改善晚峰能力”的时段结论。

## 6. 论文仍需的证据类型

下表只定义证据缺口，不规定如何获得或先做哪一项。

| 论文问题 | 所需证据 |
|---|---|
| 午间是否充电 | 各方法 10:00--15:59 的充电量、充电价格和风光对齐程度 |
| 电量是否保留到晚峰 | 午间结束 SOC、17:00 SOC、跨时段 SOC 轨迹 |
| 晚峰是否可交付 | 17:00--21:59 的承诺、要求激活、交付、未交付与恢复 |
| 午间充电贡献多少 | 禁止午间充电或等价反事实的成对差 |
| 联合价值来自哪里 | 仅能量、仅备用、固定规则和联合决策的同协议分解 |
| 风险方法是否有效 | 给定目标下的实际未交付偏差、收益代价与固定参数前沿 |
| 经济性是否稳健 | 退化成本、效率、备用持续时间和 E/P 比敏感性 |
| 结论是否可确认 | 未参与模型选择的未来 DK1 样本 |

## 7. 允许与禁止的论文主张

| 状态 | 主张 |
|---|---|
| 已允许 | DK1 存在午间低价/高风光占比与晚峰高能量价/高上调容量价的时段差异 |
| 已允许 | 在当前同协议仿真中，历史概率场景相对点预测增收并降低未交付 |
| 已允许 | 复杂依赖结构和固定风险参数没有形成稳定、全面优势 |
| 待证据 | 联合决策增加新能源富余时段充电并提高晚峰可交付能力 |
| 待证据 | 午间充电对晚峰 SOC、容量和交付具有可量化贡献 |
| 待证据 | 基于延迟实损的调整优于固定风险前沿 |
| 禁止 | 储能降低了实际弃风弃光或晚峰失负荷 |
| 禁止 | 模拟动作等同真实电站运行 |
| 禁止 | 首次研究日前＋aFRR、顺序市场、概率场景或在线储能风险控制 |
