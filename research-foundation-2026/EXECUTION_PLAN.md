## 2. 市场耦合与时段事实

### 2.1 能量与备用的资源竞争

主实验储能为 4 MW / 8 MWh、往返效率 0.85、初始与终端 SOC 4.4 MWh。备用承诺、日前能量计划和实时激活共享同一功率与能量边界。

已有耦合审计表明：容量收入与单次循环能量套利在不同日期均可能占优，储能不能把两个市场的独立最优收益直接相加。每承诺 1 MW 上调容量，实际每日激活能量均值为 3.222 MWh，90% 分位数为 5.911 MWh，最高为 12.355 MWh。

### 2.2 午间与晚峰

按丹麦本地时间描述，不改变现有结算口径：

| 指标 | 午间 10:00--15:59 | 晚峰 17:00--21:59 |
|---|---:|---:|
| 日前均价 | 64.52 EUR/MWh | 129.10 EUR/MWh |
| 日前负价占比 | 7.72% | 0.52% |
| 上调容量均价 | 9.84 EUR/MW | 36.86 EUR/MW |
| 风光/负荷均值 | 0.800 | 0.713 |
| 风光发电均值 | 2,913 MWh/h | 2,231 MWh/h |
| 净负荷均值 | 703 MWh/h | 857 MWh/h |

335 天中，89.9% 的日期晚峰日前均价高于午间；晚峰—午间价差均值为 64.57 EUR/MWh。晚峰上调容量价相对午间的按日均值差为 27.02 EUR/MW，95% 块外探索区间为 23.94--30.21 EUR/MW，93.7% 的日期为正。

331 个发用电完整日中，午间到晚峰的风光下降与净负荷上升相关系数为 0.923。上述统计是问题画像，尚未形成预注册确认性检验。

## 4. 已完成的决策实验

### 4.1 自制基线

| 方法 | 含义 | 总收益（EUR） | 聚合未交付占比 |
|---|---|---:|---:|
| B0 | 仅日前能量 | 174,085 | 0 |
| B1 | 简单顺序参与 | 433,618 | 7.38% |
| B2_FB0 | 点预测联合 | 567,075 | 12.86% |
| B3_hist_paired | 历史配对概率场景 | 635,939 | 8.86% |
| B3_pooled_gaussian | 合并高斯场景 | 661,826 | 10.48% |
| Oracle | 完美信息条件上界 | 824,744 | 0 |

`B3_hist_paired` 相对 `B2_FB0`：

| 指标 | χ=0 | χ=0.5 |
|---|---:|---:|
| 日收益差 | +326.37 EUR | +301.59 EUR |
| 95% 区间 | 195.31--475.18 | 173.81--443.41 |
| 日级未交付占比差 | -1.462 个百分点 | -1.499 个百分点 |
| 95% 区间 | -2.627 至 -0.450 | -2.663 至 -0.514 |

结果支持“概率分布相对点预测具有决策价值”。它没有说明储能在何时充电或何时保留 SOC。

### 4.2 已发表方法的同协议重建

| 方法 | 总收益（EUR） | 聚合未交付占比 | 证据角色 |
|---|---:|---:|---|
| X06 | 625,291 | 11.90% | 概率交付约束 |
| X09 | 657,026 | 9.66% | 顺序随机优化 |
| X14，χ=0 | 615,684 | 11.80% | 三阶段历史场景与 CVaR |
| X14，χ=0.5 | 523,372 | 10.11% | 固定风险厌恶敏感性 |

这些结果是按本仓库共同协议重建，不是原论文复现。X07 与 X13 因关键实现字段未报告而未补猜测参数。

### 4.3 风险诊断

固定风险参数没有稳定恢复实际交付校准。名义 5% VaR 的实际超越率从历史独立场景的 6.2%--8.5% 到合并高斯场景的 28.7%--31.9% 不等，全部方法中的最高值为 44.4%。

该结果说明预测风险度量不能自动替代实际交付评价；它不证明任何在线控制方法已经有效。

## 5. 当前结果没有回答什么

| 未回答内容 | 原因 |
|---|---|
| 各方法的午间充电量 | 结果文件没有保存逐时充放电轨迹 |
| 午间充电是否来自新能源 | 缺少电量来源追踪和系统反事实 |
| 17:00 SOC 及其来源 | 结果只保存日级汇总 |
| 晚峰承诺和交付的时段分解 | 未按 17:00--21:59 汇总 |
| 禁止午间充电后的晚峰变化 | 尚无对应反事实 |
| 仅备用与固定午充晚备的价值 | 尚无这两个分解基线 |
| 退化后的净收益 | 只报告循环次数，未计入退化成本 |
| 给定未交付目标能否实现 | 尚无基于实际损失的结果 |
| 未来样本能否确认 | 当前测试集已经用于预测与决策比较 |

## 6. 开放研究空间

下列项目只记录可研究对象，不构成执行步骤：

| 研究对象 | 可能形成的证据 |
|---|---|
| 逐时动作与 SOC | 午间充电、17:00 SOC、晚峰承诺和交付的可解释轨迹 |
| 禁止午间充电反事实 | 午间充电对晚峰能力与收益的边际贡献 |
| 仅备用、固定午充晚备 | 分解能量价值、备用价值和优化价值 |
| 基于实际未交付的自适应承诺 | 检验风险目标、收益代价和反馈延迟影响 |
| 退化成本 | 检验毛收益排序是否转化为净收益排序 |
| 备用持续时间与跨日 SOC | 检验物理假设敏感性 |
| 季节与高风光/高价日 | 检验时段机制是否由少数日期驱动 |
| 未来 DK1 数据 | 对未参与设计的样本作确认性评价 |

研究过程中可以增加、合并或放弃这些方向。任何形成论文主张的实验都必须使用同信息集、同物理可行域和同结算层，并记录环境指纹、随机种子及失败情况。
