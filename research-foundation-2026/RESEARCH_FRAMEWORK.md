# 研究框架：DK1 午间新能源富余充电与晚峰上调备用

## 1. 要解决的问题

本分支研究一座价格接受者储能能否在 DK1 市场中形成以下跨时段作用：

> 在午间新能源富余、日前价格较低时充电，并在晚峰保留足够 SOC 与放电功率，提供可交付的 aFRR 上调能力。

该问题由三个层级组成，不能互相替代：

| 层级 | 问题 |
|---|---|
| 应用问题 | 储能能否把午间新能源富余时段的充电机会转化为晚峰可用能力？ |
| 市场问题 | aFRR 容量先于日前能量关闭时，提前承诺如何影响后续充电、放电和 SOC？ |
| 方法问题 | 面对价格、激活和交付不确定性，什么决策方式能改善午间充电、晚峰交付、收益与风险之间的权衡？ |

延迟反馈风险控制、概率预测、随机优化和固定时段规则都是可能的解决方式，不是研究目的。本框架暂不冻结具体方法或执行顺序。

## 2. 市场边界

| 项目 | 本分支设定 |
|---|---|
| 区域 | DK1 |
| 参与者 | 一座 4 MW / 8 MWh 的模拟价格接受者储能 |
| 能量市场 | 15 分钟日前能量 |
| 备用市场 | 小时级 aFRR 上调容量及其 15 分钟实际激活 |
| 容量闸门 | D-1 07:30 CET |
| 容量结果 | 正常情况下 D-1 09:20 CET 前公布 |
| 日前闸门 | D-1 12:00 CET |
| 实时层 | 实际上调激活、激活价格、不平衡价格与 SOC 恢复 |
| 不纳入 | 下调 aFRR、FCR、mFRR、日内市场、网络出清、真实储能报价和现场控制 |

两个闸门形成真实顺序：07:30 决定备用承诺时，交割日日前价格尚未公布；12:00 安排日前能量时，aFRR 容量结果已经公布。市场时序、单位和可见性以 [DK1 数据字典](../data/multi_market_energy_reserve/DATA_DICTIONARY.md) 为准。

## 3. “午间消纳”的可测边界

DK1 数据包含实际风光发电、负荷、交换和价格，但不包含真实弃风弃光、限发指令或反事实系统出清。储能动作也由模型生成而非现场观测。

| 可以评价 | 不能据此声称 |
|---|---|
| 10:00--15:59 的模型充电量 | 实际弃风弃光减少量 |
| 负价格时段的模型充电量 | 储能改变了 DK1 出清价格 |
| 风光/负荷较高时段的对齐充电量 | 每一 MWh 充电均来自新能源 |
| 午间结束与 17:00 的模型 SOC | 实网晚峰可靠性改善 |
| 17:00--21:59 的上调承诺、要求激活、实际交付与未交付 | 晚峰未供电量下降 |
| 禁止午间充电反事实下的模型结果差 | 现场因果效果 |

论文中使用“新能源富余时段对齐充电”“潜在新能源吸收”“午间—晚峰能量转移”。只有取得弃电或限发数据并建立系统级反事实后，才使用“实际弃电削减”。

## 4. 核心研究问题

### RQ1：时段错配是否存在

DK1 是否稳定存在午间风光占比较高、日前价格较低，而晚峰净负荷、日前价格或上调容量价格较高的结构？

### RQ2：联合决策是否形成午间—晚峰转移

相对于仅能量、仅备用、固定午充晚备和分离决策，联合决策是否增加新能源富余时段的充电，并提高晚峰 SOC、上调承诺与实际交付？

### RQ3：不确定性如何改变跨时段作用

点预测、概率场景和不同依赖结构如何改变午间充电、晚峰备用、收益和未交付之间的关系？

### RQ4：实际交付风险能否被控制

当实际未交付结果延迟可见时，基于已实现交付损失调整后续承诺，能否比固定风险参数更接近预设风险水平且不被其收益—风险前沿支配？

RQ4 是开放问题。它可以成为方法贡献，但不取代 RQ1--RQ3 的应用问题。

## 5. 数据与证据角色

本分支的实证主数据只使用 Energinet DK1。其他本地数据集不与 DK1 行级拼接，也不进入本分支的主结论。

| DK1 数据 | 决策时角色 | 评价时角色 |
|---|---|---|
| 日前价格 | 预测目标；历史可见值可作输入 | 能量结算与时段价差 |
| 上调容量价格、需求与采购量 | 07:30 预测目标；09:20 后结果可进入 12:00 决策 | 容量结算与晚峰稀缺性 |
| 上调激活量和价格 | 历史可见值可作输入 | 实际激活、交付和激活收入 |
| 不平衡价格 | 历史可见值可作输入 | 恢复、偏差和未交付结算 |
| 风光预测 | 仅在对应闸门前已发布时可用 | 预测消融 |
| 发用电结算 | 因发布延迟不能作为同日输入 | 风光占比、净负荷和时段解释 |

任一特征都必须满足 `available_at <= decision_time`。观测量与模型生成量的记录规则见 [CONVENTIONS.md](../CONVENTIONS.md)。

### 6.1 数据事实

| 事实 | 当前实测值 |
|---|---:|
| aFRR 容量小时数 | 8,040 |
| 日前及激活的 15 分钟记录数 | 各 32,160 |

这些数值支持 RQ1 的问题动机，不等于储能已经完成跨时段转移。

### 6.2 已完成的决策结果

| 方法 | 总收益（EUR） | 聚合未交付占比 |
|---|---:|---:|
| B0 仅日前能量 | 174,085 | 0 |
| B1 简单顺序参与 | 433,618 | 7.38% |
| B2_FB0 点预测联合 | 567,075 | 12.86% |
| B3_hist_paired 概率场景联合 | 635,939 | 8.86% |
| B3_pooled_gaussian | 661,826 | 10.48% |
| X06 同协议重建 | 625,291 | 11.90% |
| X09 同协议重建 | 657,026 | 9.66% |
| X14 同协议重建 | 615,684 | 11.80% |
| Oracle | 824,744 | 0 |

`B3_hist_paired` 相对 `B2_FB0` 日均增收 326.37 EUR，95% 区间为 195.31--475.18 EUR；日级未交付占比降低 1.462 个百分点，95% 区间为 -2.627 至 -0.450 个百分点。复杂高斯场景收益更高但未交付也更高，不能称为全面最优。

结果源见 [S3-B 汇总](../p1_paper/results/s3_comparison/arm_summary.csv)和[成对差](../p1_paper/results/s3_comparison/paired_differences.csv)。这些结果证明概率场景具有决策价值，但现有输出尚未分解午间充电、17:00 SOC 和晚峰交付，因此 RQ2 仍未回答。

## 7. 尚未回答的科学问题

| 开放问题 | 当前缺口 |
|---|---|
| 储能是否主要在新能源富余午间充电 | 缺逐时充放电输出和富余时段评价 |
| 午间充电对晚峰能力贡献多少 | 缺禁止午间充电等反事实 |
| 提前承诺备用是否挤出午间充电或日前套利 | 缺仅备用、固定午充晚备等分解基线 |
| 何种不确定性表示最有价值 | 已有日级证据，缺时段机制分解 |
| 晚峰高容量价格是否要求额外 SOC 预留 | 缺逐时承诺与 SOC 联合轨迹 |
| 实际未交付能否接近给定目标 | 延迟反馈控制尚无结果 |
| 退化是否改变方法排序 | 已有循环指标，未计入退化成本 |
| 结论是否跨季节和未来样本成立 | 当前窗口不足一年且测试集已用于既有比较 |

这些问题可以由不同方法回答。本框架不规定先后顺序，也不把某一种控制器、预测器或优化形式设为必选方案。

## 8. 可探索的研究维度

下列内容是研究空间，不是执行清单：

| 维度 | 可比较内容 |
|---|---|
| 决策结构 | 仅能量、仅备用、固定午充晚备、顺序联合、随机联合 |
| 不确定性 | 点预测、历史场景、经验依赖、受限参数依赖 |
| 时段机制 | 午间充电、17:00 SOC、晚峰承诺、激活交付、恢复 |
| 风险处理 | 固定安全余量、机会约束、CVaR、基于已实现损失的在线调整 |
| 物理假设 | 备用持续时间、效率、E/P 比、终端 SOC、跨日 SOC |
| 经济假设 | 退化成本、未交付成本、容量与激活收入 |
| 稳健性 | 季节、高价日、高风光日、未来未参与设计的数据 |

任何新增实验都应保留现有时间划分、缺失处理、信息集和共同可行域，除非另行说明理由并在运行前冻结改变。

## 9. 主张边界

当前允许写入论文的结论只有：

1. DK1 观测数据存在午间与晚峰的价格、风光和上调容量时段差异；
2. 在当前模拟储能和统一协议下，简单概率场景相对点预测同时提高收益并降低未交付；
3. 复杂依赖结构和固定风险参数没有形成稳定、全面的优势。

在取得新结果前，不声称：

- 联合策略已经增加午间新能源吸收；
- 储能已经降低实际弃电或晚峰失负荷；
- 延迟反馈能够控制给定未交付目标；
- 当前仿真代表真实电站运行；
- 日前能量与 aFRR 联合优化、随机优化或在线储能风险控制本身属于首次提出。
