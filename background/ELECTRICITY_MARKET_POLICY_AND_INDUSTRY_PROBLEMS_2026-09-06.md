# 电力市场最新政策、运行结果与行业问题

**研究起点版本：2026-09-06**  
**信息截止时间：2026年9月6日（Asia/Shanghai）**  
**研究范围：中国电力市场为主；只讨论政策、市场运行和行业问题，暂不预设模型、代码框架或论文技术路线。**

---

## 1. 文档目的与证据边界

本文档用于重新建立研究起点，回答三个问题：

1. 截至2026年9月6日，中国电力市场最新的重要政策是什么？
2. 最新公开运行数据说明市场发展到了什么阶段？
3. 政策目标与实际运行之间暴露了哪些行业问题？

文中将证据分为三类：

- **正式政策**：国家发展改革委、国家能源局等发布的规则、规划和通知。
- **确认结果**：官方发布的交易量、装机量、市场运行案例和监管处理结果。
- **分析判断**：根据正式政策和确认结果作出的行业解释，不等同于监管部门认定的违法违规结论。

截至2026年9月6日，2026年度全国电力领域综合监管仍处于问题处置阶段，全国性最终监管总结尚未公开。因此，不能把监管文件列出的风险全部表述为已经确认的全国普遍问题。

## 2. 核心判断

中国电力市场已经从“扩大市场化交易规模”进入“多市场、多主体、多时间尺度协同运行”的阶段。当前最突出的矛盾不再是有没有市场，而是：

1. 新能源全面入市后，价格风险和偏差责任如何管理；
2. 午间新能源过剩与晚间保供压力如何同时解决；
3. 中长期、现货、辅助服务、容量、零售、绿电市场如何衔接；
4. 储能、虚拟电厂和可调负荷如何获得稳定且不重复的价值回报；
5. 省内、省间和跨电网经营区交易如何统一规则并服从物理安全约束；
6. 信息披露、计量结算、市场力监测和数字化监管能否跟上交易复杂度；
7. 预测和人工智能系统能否在数据缺失、规则变化、极端天气和市场突变下可靠运行。

这意味着未来行业研究不应只关注“预测平均电价”，而应关注价格、出力、偏差、阻塞、风险和经营决策的联合问题。

### 2.1 本项目当前研究定位（2026-09-07 更新）

本项目不再把“午间新能源消纳—晚峰保供”本身作为论文的唯一主问题，而将其作为高比例新能源下多市场耦合最清晰的行业背景。当前主问题是：**联合预测电能量与备用市场的相关状态，并协调储能的能量交易、备用承诺与跨时段 SOC，在避免能力重复承诺的同时改善收益、新能源消纳、晚峰可靠性与备用可交付性。**

具体目标、首篇论文边界、研究问题和实验矩阵见：[Q3 背景下的多市场联合预测与协同决策](MULTI_MARKET_FORECASTING_RESEARCH_TARGET_2026-09-07.md)。

## 3. 截至截止日最近的行业动态

### 3.1 2026年9月4日：广西讨论统一调度、市场风险处置和厂网分开

南方能源监管局与广西能源主管部门讨论了：

- 广西电力系统统一调度；
- 电力市场风险处置；
- 局部供电营业区划分调整；
- 相关经营主体厂网分开；
- 抽水蓄能开发与新能源消纳。

这表明在全国统一市场建设过程中，部分地区仍需继续理顺地方电网、电源运营、统一调度和公平竞争之间的关系。

来源：[南方能源监管局与广西壮族自治区能源局座谈共商能源电力发展重点事项](https://www.nea.gov.cn/20260904/22a41328599a4375863ec5abb90a80b2/c.html)

### 3.2 2026年9月2日：华中四省互济市场公布首月结果

华中区域东四省互济交易自2026年7月1日连续结算试运行后，首月结果包括：

- 653家主体完成交易；
- 交易电量超过5亿千瓦时；
- 最大跨省互济电力353.3万千瓦；
- 29家储能电站和1家虚拟电厂实现出清；
- 抽水蓄能跨省最大调节电力90万千瓦；
- 帮助327家新能源企业减弃增发近1亿千瓦时。

官方同时指出，2026年7月华中地区出现了“晚间保供与午间消纳问题交织”的运行状态。这是当前源网荷储协调最典型的行业矛盾之一。

来源：[华中区域（东四省）电力互济交易首月运行成效](https://www.nea.gov.cn/20260902/24519b4010bb43a192c3b6b0dbdba1d2/c.html)

### 3.3 2026年9月2日：国家能源局部署新型电网建设

国家能源局判断，“十五五”时期中国电力需求仍将保持年均约5%的增长，同时新能源占比继续提高，高端产业对绿色、高质量电能的需求增加。

这意味着未来电力系统同时面对：

- 总量增长；
- 高比例新能源；
- 高可靠性要求；
- 算力、先进制造等新型负荷；
- 更复杂的源网荷储互动。

来源：[国家能源局召开新型电网建设工作部署会](https://www.nea.gov.cn/20260902/6a6147bd0a244735af4c28e3e285af6f/c.html)

### 3.4 2026年9月2日：上海继续补齐数字化监管短板

华东能源监管局提出继续优化上海电力市场数字化监管系统，包括：

- 系统功能优化；
- 监管指标体系完善；
- 数据归集强化；
- 预警阈值调整；
- 个性化监管指标建设。

这说明市场数字化监管仍处于持续建设阶段，数据完整性、指标有效性和风险预警能力尚未完全成熟。

来源：[华东能源监管局召开上海数字化监管工作推进会](https://www.nea.gov.cn/20260902/ef1f429f5ab34379a6c950866c3e9fcd/c.html)

## 4. 2026年最新全国市场运行结果

### 4.1 2026年1—7月全国电力市场交易

截至2026年7月底：

| 指标 | 交易量 | 同比变化 |
| --- | ---: | ---: |
| 全国市场交易总量 | 44252亿千瓦时 | +23.4% |
| 省内交易 | 34626亿千瓦时 | +26.8% |
| 跨省跨区交易 | 9626亿千瓦时 | +12.5% |
| 中长期交易 | 39354亿千瓦时 | — |
| 现货交易 | 4898亿千瓦时 | — |
| 绿电交易 | 1918亿千瓦时 | +5.6% |
| 电网代理购电 | 4857亿千瓦时 | — |

据上述数据计算：

- 中长期交易约占市场交易总量的88.9%；
- 现货交易约占11.1%；
- 跨省跨区交易约占21.8%；
- 绿电交易约占4.3%。

这些比例不直接代表市场设计优劣，但说明中长期交易仍承担主要电量配置作用，现货价格发现、跨省资源配置和绿色价值交易仍处于继续扩展阶段。

来源：[2026年1—7月全国电力市场交易电量同比增长23.4%](https://www.nea.gov.cn/20260827/86a3984d71804083b3ddabc50d74068a/c.html)

### 4.2 2026年上半年结果

2026年上半年全国市场交易电量达到36848亿千瓦时，同比增长24.2%。其中：

- 中长期交易32568亿千瓦时，占88.4%；
- 现货交易4280亿千瓦时；
- 跨省跨区交易7713亿千瓦时，同比增长12.1%；
- 绿电交易1641亿千瓦时，同比增长6.6%。

全国已有山西、山东、浙江等19个省份的中长期市场实现全年无休、每日开市。其目的之一，是降低周末、节假日天气和负荷快速变化时因交易窗口不足产生的偏差。

来源：[2026年上半年我国电力市场交易电量规模同比增长24.2%](https://www.nea.gov.cn/20260730/0b9c11dc62e54cabac8480f2c24b6838/c.html)

### 4.3 2025年度市场基础结果

2025年全国电力市场交易电量达到6.64万亿千瓦时，同比增长7.4%，约占全社会用电量的64%。同时：

- 跨省跨区交易1.59万亿千瓦时，同比增长11.6%；
- 绿电交易3285亿千瓦时，同比增长38.3%；
- 多年期绿电协议成交约600亿千瓦时；
- 市场注册经营主体超过100万家。

截至2025年底：

- 省级现货市场基本全覆盖；
- 中长期市场连续运行全覆盖；
- 21个省区或地区实现新能源“报量报价”参与现货市场；
- 多地将实时市场出清粒度由15分钟推进到5分钟。

来源：

- [国家能源局介绍2025年全国电力市场交易成效](https://www.nea.gov.cn/20260130/8f698dfb4ebe4a5d93b5507b6a47d888/c.html)
- [《2025年度中国电力市场发展报告》发布](https://www.nea.gov.cn/20260618/41e848b9ec6543998757db3864e01ab2/c.html)

## 5. 2025—2026年关键政策

### 5.1 《新型电力系统建设“十五五”规划》

发布时间：2026年8月3日；文件日期：2026年7月21日。

规划给出的2030年主要目标包括：

| 指标 | 2025年基础 | 2030年目标 |
| --- | ---: | ---: |
| 全国发电总装机 | 38.9亿千瓦 | 54亿千瓦 |
| 非化石能源发电装机占比 | 61.7% | 65% |
| 非化石能源发电量占比 | 42.3% | 50% |
| 省间电力互济能力 | 8000万千瓦 | 1.2亿千瓦 |
| 配电网承载分布式新能源能力 | 5亿千瓦 | 9亿千瓦 |
| 需求侧削峰能力占最大负荷比重 | 超过3% | 超过5% |
| 虚拟电厂最大调节能力 | 1685万千瓦 | 超过5000万千瓦 |
| 新型储能装机 | 1.36亿千瓦 | 3亿千瓦 |
| 市场交易电量占比 | 64% | 70% |
| 跨省跨区交易电量 | 1.59万亿千瓦时 | 2万亿千瓦时 |

规划还提出：

- 全国新能源利用率保持在约90%，并按地区设置原则上不低于95%、90%或85%的分档目标；
- 建立新能源“规划—建设—并网—消纳”全周期监测预警；
- 推动长时间尺度、高精度新能源功率预测大范围应用；
- 推动虚拟电厂常态化、规模化参与市场；
- 到2030年需求侧削峰能力超过1亿千瓦；
- 到2030年车网互动聚合可调充电规模力争达到5000万千瓦。

来源：[《新型电力系统建设“十五五”规划》](https://www.ndrc.gov.cn/xxgk/zcfb/tz/202608/P020260803594268920789.pdf)

### 5.2 完善发电侧容量电价机制

发布时间：2026年1月30日。

政策覆盖煤电、气电、抽水蓄能和电网侧独立新型储能，提出：

- 对符合条件的独立储能建立容量电价；
- 在现货市场连续运行地区建立可靠容量补偿机制；
- 补偿依据由单纯装机容量转向顶峰时段可持续、稳定供电的可靠容量；
- 容量补偿、电能量市场和辅助服务收益需要统筹，避免重复补偿。

该政策意味着电源和储能的收入结构将从单一电量收入转向“电能量＋辅助服务＋容量价值”的组合。

来源：[关于完善发电侧容量电价机制的通知](https://www.ndrc.gov.cn/xxgk/zcfb/tz/202601/t20260130_1403524.html)

### 5.3 修订省间电力现货交易规则

发布时间：2026年4月24日。

新版规则要求：

- 强化省间现货与省内现货衔接；
- 强化省间现货与中长期市场衔接；
- 扩大交易范围；
- 研究用户侧直接参与省间现货市场；
- 完善计量、结算、风险防控和应急处置机制。

来源：[关于修订省间电力现货交易规则的复函](https://www.ndrc.gov.cn/xwdt/tzgg/202604/t20260424_1404879_ext.html)

### 5.4 多用户绿电直连

发布时间：2026年5月20日；文件日期：2026年5月14日。

政策允许工业园区、零碳园区、增量配电网、算力设施和出口型企业等组织多用户绿电直连。主要要求包括：

- 按“以荷定源”规划新能源规模；
- 年自发自用电量原则上不低于总可用发电量的60%；
- 自发自用电量占总用电量比例不低于30%，2030年前不低于35%；
- 并网型项目需要接受统一调度；
- 项目整体参与市场时，由主责单位承担内部平衡和市场申报责任。

来源：[关于有序推动多用户绿电直连发展有关事项的通知](https://www.ndrc.gov.cn/xwdt/tzgg/202605/t20260520_1405314_ext.html)

发布时间：2025年2月9日；文件日期：2025年1月27日。

- 对符合条件的项目建立市场外差价结算机制。

## 6. 主要行业问题

## 6.1 新能源全面入市后的价格、偏差和收益风险

新能源全面入市后，项目不再只面对发多少电的问题，还需要面对：

- 日前申报电量与实际出力偏差；
- 日前与实时价格差；
- 午间低价或负价；
- 限电、弃电和跨省外送不确定性；
- 机制电价与市场均价差额结算；
- 绿证、电能量、辅助服务和容量收益的组合；
- 不同省份规则和限价区间差异。

**行业本质问题：**新能源的天气风险正在转化为市场价格风险和结算风险。

## 6.2 午间新能源消纳与晚间电力保供并存

高比例光伏系统经常在午间形成低净负荷甚至电力富余，但晚峰光伏快速退出、居民和工业负荷仍处高位。

行业需要同时解决：

- 午间储能充电和可调负荷转移；
- 晚峰储能放电、火电顶峰和跨省购电；
- 日内大幅净负荷爬坡；
- 连续阴雨、低风等新能源低出力事件；
- 极端高温导致的负荷预测偏差。

**行业本质问题：**新能源“电量充足”不等于高峰时段“容量充足”。

## 6.3 中长期与现货市场衔接不足

当前中长期交易仍占市场交易总量近九成。它承担保供和稳定经营预期的作用，但也产生新的衔接问题：

- 年度、月度合同曲线与实际分时曲线不匹配；
- 合同调整频率不足会放大偏差；
- 中长期结算参考点与节点现货价格之间可能出现基差；
- 固定价合同难以及时反映燃料和供需变化；
- 中长期高比例签约可能削弱现货价格信号；
- 现货高波动又可能增加主体经营风险。

**行业本质问题：**需要同时实现长期稳定和短期灵活，而两者并非天然一致。

## 6.4 省内、省间和区域市场仍未完全一体化

跨省交易受到市场规则和物理电网双重约束：

- 不同省份交易时序、限价和结算方式不同；
- 省间交易与省内现货可能使用不同参考点；
- 输电通道容量可能在关键时段饱和；
- 送端新能源消纳利益与受端保供利益需要协调；
- 用户、售电公司、新型储能直接参与省间交易仍在拓展；
- 跨经营区交易需要解决计量、结算和风险分担。

**行业本质问题：**电力能够跨区流动，但市场规则、价格信号和责任机制尚未完全同步。

## 6.5 节点价格、阻塞和位置价值逐渐显性化

随着新能源和储能集中接入，统一分区价格可能无法准确表达：

- 局部电网阻塞；
- 不同节点的边际供电成本；
- 储能在不同位置的调节价值；
- 新能源富集区和负荷中心之间的输电约束。

山西2026年进一步采用上下网侧节点电价，引导储能在阻塞和新能源大发时段科学充放电。上半年相关调节机制增加清洁能源消纳10.6亿千瓦时、利用率提高1.8个百分点。

来源：[山西完善市场调节机制](https://www.nea.gov.cn/20260821/5ae2c8402ba34e6e8eac5361f103a059/c.html)

**行业本质问题：**灵活性资源不仅具有时间价值，也具有位置价值。

## 6.6 储能装机扩张与商业收益不确定并存

截至2025年底，全国新型储能累计装机达到1.36亿千瓦、3.51亿千瓦时，同比增长84.3%。

来源：[中国新型储能发展报告（2026）](https://www.nea.gov.cn/20260730/0a1e9823b7a14e8ba16e82c34b3bea2b/c.html)

主要问题包括：

- 容量补偿能否覆盖固定成本；
- 现货价差能否长期覆盖损耗和退化成本；
- 调频、备用、爬坡等收入是否稳定；
- 新能源配建储能是否被有效调用；
- 多个储能采用相同策略时是否会压缩价差；
- 节点位置和持续放电时间如何影响容量价值；
- 不同收益来源是否存在重复补偿或责任重叠。

**行业本质问题：**装机容量增长不等于可调能力增长，也不等于项目经济性成立。

## 6.7 虚拟电厂由试点走向规模化仍有基础性障碍

虚拟电厂需要聚合分布式电源、储能、充电设施和可调负荷，但面临：

- 可调能力申报不准确；
- 用户响应的不确定性；
- 基线负荷认定争议；
- 持续响应时间不足；
- 跨节点聚合与局部阻塞不匹配；
- 现货、辅助服务和需求响应准入规则不一致；
- 未完成响应时的考核和赔偿责任；
- 商业模式仍可能依赖补贴或单一需求响应收入。

**行业本质问题：**虚拟电厂需要把“理论聚合容量”转化为可验证、可调用、可结算的可靠调节能力。

## 6.8 售电公司批零倒挂与风险错配

截至2025年底，全国注册售电公司5288家，代理70余万家电力用户，零售交易电量占市场化交易电量约六成。

2026年8月，湖南能源监管部门公开列出的零售市场问题包括：

- 商业模式单一和能力短板；
- 价格失序、失真；
- 批零倒挂；
- 风险错配；
- 信息不对称和信任危机；
- 垄断与市场活力不足；
- 监管和争议救济不及时。

来源：

- [国家能源局介绍2026年零售市场监管方向](https://www.nea.gov.cn/20260130/0f126941f50c4c668ba13773f599d6db/c.html)
- [湖南能源监管办组织电力零售市场专题研讨](https://hunb.nea.gov.cn/dtyw/jgdt/202608/t20260810_306412.html)

**行业本质问题：**零售固定价格、批发现货价格和用户偏差责任之间缺少充分匹配的风险机制。

## 6.9 市场信息披露仍不充分、不及时或不统一

2026年7月，南方能源监管局针对部分售电公司未按规定时限披露信息的问题责令整改，并将其纳入市场信用评价。

来源：[南方能源监管局加强电力市场信息披露监管](https://nfj.nea.gov.cn/xwzx/jgdt/202607/t20260717_304963.html)

行业数据问题主要包括：

- 不同省份字段、格式和时间粒度不一致；
- 关键报价、检修、备用和阻塞信息公开程度不同；
- 数据发布时间与市场申报时点可能不匹配；
- 修订数据缺少清晰的版本和发布时间记录；
- 市场规则文本缺少机器可读结构；
- 商业秘密保护与公平信息获取之间存在张力。

**行业本质问题：**没有可验证的信息时间边界，就无法确认预测、报价和监管分析是否使用了当时真正可获得的数据。

## 6.10 市场力、串通报价和发售一体风险

2026年综合监管把市场支配地位、串通报价、发售一体不正当竞争和不规范信息披露列为重点。

山西数字化监管系统已经针对断面阻塞时的市场力行使、小额高频串通报价、批零价差等问题开展监测。2026年以来累计发现2起违规交易线索，涉及12家发电企业、1家售电公司和1家批发用户。

来源：[山西深化数智化电力市场监管](https://www.nea.gov.cn/20260710/ee93eb4a6d97437d83f4f769a36fbfd7/c.html)

**行业本质问题：**价格异常既可能来自真实供需紧张，也可能来自阻塞条件下的策略性行为，两者必须区分。

## 6.11 配电网承载能力制约分布式新能源发展

分布式光伏、充电设施、用户侧储能和微电网大量接入后，配电网面临：

- 反向潮流；
- 局部过电压和配变过载；
- 新能源接入“红区”；
- 配电网可观、可测、可控能力不足；
- 配电网投资与新能源建设速度不匹配；
- 局部消纳和公共电网安全责任边界不清晰。

“十五五”规划要求到2030年将配电网承载分布式新能源能力提高到9亿千瓦，并动态消除接入卡点。

**行业本质问题：**新能源装机潜力正在受到局部电网承载力而非全国总装机空间的限制。

## 6.12 绿电、绿证、碳市场和直连模式之间需要统一价值核算

2026年6月，全国交易绿证8273万个，其中绿电交易对应绿证4289万个。单独交易绿证价格按生产年份出现明显差异：

- 2024年电量对应绿证平均1.29元/个；
- 2025年电量对应绿证平均4.05元/个；
- 2026年电量对应绿证平均5.96元/个。

来源：[2026年6月全国绿证核发及交易数据](https://www.nea.gov.cn/20260724/d35b8a39fb724572b3d3ce3cbed9d4e9/c.html)

主要问题包括：

- 电能量价格和环境价值如何拆分；
- 不同生产年份和电源类型的绿证如何定价；
- 绿证与碳市场、CCER如何避免重复核算；
- 多年期绿电协议如何管理价格和履约风险；
- 绿电直连项目如何进行内部电量分配和偏差结算；
- 企业绿色用能声明如何验证和追溯。

**行业本质问题：**绿色属性已经成为独立商品，但其定价、核算和风险管理体系仍在形成。

## 6.13 人工智能从示范走向生产系统仍缺少可靠性证据

政策已经明确推动高精度新能源功率预测、电力市场智能运营、虚拟电厂和算电协同。但生产应用仍需解决：

- 高质量、跨主体数据难以共享；
- 训练数据与生产市场规则不一致；
- 数据缺失、延迟、错位和修订会导致模型失效；
- 极端天气、负价和价格尖峰样本不足；
- 模型平均误差下降不一定转化为经营收益；
- 模型决策难以解释和追责；
- 网络安全、商业秘密与数据开放冲突；
- 缺乏统一的上线测试、漂移监测和失效回退标准。

**行业本质问题：**行业需要的不是离线排行榜第一，而是信息边界真实、风险可控、结果可验证、失效可回退的决策系统。

## 7. 行业问题之间的因果关系

当前问题不是相互独立的，而是形成一条连续链条：

```text
新能源装机快速增长
        ↓
天气驱动的出力波动和预测误差扩大
        ↓
午间富余、晚峰紧张、净负荷爬坡加剧
        ↓
负价、尖峰、区域价差和实时偏差增加
        ↓
储能、虚拟电厂、跨省互济的价值上升
        ↓
现货、辅助服务、容量和零售市场更加复杂
        ↓
信息披露、计量结算、风险管理和市场监管压力上升
        ↓
预测系统必须从单一价格点预测升级为概率、场景和决策支持
```

---

## 8. 行业问题优先级

### 第一优先级：已经影响日常市场运行

1. 新能源入市后的偏差和收益风险；
2. 午间消纳与晚峰保供并存；
3. 中长期、现货和实时市场衔接；
4. 储能调用和多市场收益；
5. 售电公司批零倒挂与履约风险；
6. 信息披露和市场风险预警。

### 第二优先级：全国统一市场继续深化的关键约束

1. 省内、省间和区域市场协调；
2. 节点价格与阻塞管理；
3. 市场力和策略性报价识别；
4. 配电网承载分布式新能源；
5. 绿电、绿证、碳市场和直连核算。

### 第三优先级：未来五年需要规模化突破

1. 虚拟电厂稳定响应和商业模式；
2. 车网互动；
3. 算力与电力市场协同；
4. 长时储能和可靠容量评价；
5. 人工智能生产级可靠性和行业数据基础设施。

## 9. 后续研究应优先收集的数据

在确定任何论文或模型之前，应先判断能否取得以下数据：

| 问题方向 | 最低必要数据 |
| --- | --- |
| 新能源偏差风险 | 日前功率预测、实际出力、日前价格、实时价格、偏差结算规则 |
| 负价与价格尖峰 | 分时现货价格、负荷预测、风光预测、备用、检修、联络线和限价规则 |
| 储能经营 | 日前/实时价格、辅助服务价格、调用记录、SOC、效率、功率、容量、退化成本 |
| 跨省互济 | 省内价格、省间成交、可用输电能力、联络线计划与实际潮流 |
| 节点阻塞 | 节点价格、网络拓扑、线路限额、阻塞断面、机组和负荷位置 |
| 市场力 | 主体级报价曲线、机组容量、可用状态、边际机组和市场份额 |
| 售电风险 | 批发采购、零售合同、用户负荷、偏差、保证金、结算和违约数据 |
| 虚拟电厂 | 用户基线、实时负荷、响应指令、实际响应、可用容量和考核结果 |
| 绿电与绿证 | 绿电合同、电能量价格、绿证价格、生产年份、结算和企业消费数据 |
| AI可靠性 | 原始值、预测值、修订值、发布时间、缺失记录、系统告警和模型版本 |

如果缺少对应数据，就不能仅靠更复杂的预测模型宣称解决相关行业问题。

## 10. 本阶段结论

截至2026年9月6日，中国电力市场最值得继续研究的不是单纯提高平均电价预测精度，而是以下三类问题：

1. **新能源、负荷和市场状态不确定性如何传递为价格与结算风险；**
2. **价格和风险预测如何转化为储能、售电、新能源和虚拟电厂的可靠决策；**
3. **跨市场、跨区域、规则变化和数据异常条件下，预测与决策系统是否仍然有效。**

下一阶段应从本文件列出的行业问题中选择一个具体经营主体、一个明确决策、一个可获得的数据集合，再建立论文问题和技术路线，而不是先选择模型。
